# 简体中文界面

这是基于 [T3 Code](https://github.com/pingdotgg/t3code) 的非官方中文分支，保留原项目 MIT 许可证与版权声明。不是官方中文发行版，也不代表原团队提供支持。

## 切换语言

打开 **Settings → General → Language → Interface language**，选择 **简体中文**。也可以在设置搜索中输入“语言”或“Interface language”。随时选择 **English** 切回英文，无需重启。

第一次打开时，Web 版跟随浏览器首选语言，桌面应用跟随系统首选语言：中文使用简体中文，其他语言使用英文。之后可随时按上面的方法切换。选择只保存在当前浏览器或桌面客户端，不会同步到其他设备。浏览器禁止存储时，本次会话仍可切换，但重启后可能无法保留。

## 当前范围

目前已覆盖 Web 与桌面共用界面的设置、侧边栏、会话、命令面板、Git、PR、文件预览、浏览器、设备和用量等主要区域。未完成的页面、部分旧格式文件预览和设备诊断仍可能显示英文；原生 iOS/Android 客户端尚未汉化。

全部译文的英中对照见仓库里的 `i18n/zh-CN.json`。项目名、文件路径、代码、终端输出、模型回复和第三方错误原文不会自动翻译。界面语言不改变模型语言，也不修改任何服务端协议。

桌面应用的原生菜单、右键菜单和“检查更新”提示框在系统首选语言为中文时显示简体中文；它们不跟随上述 Web 界面语言选择，系统语言变更后需重启应用。启动恢复、浏览器权限和通行密钥等少数系统弹窗仍显示英文。

## 与官方版本的关系

中文分支沿用官方的应用标识、`t3code://` 登录回跳协议、`~/.t3` 数据目录和 `t3` 命令，以便账号登录、T3 Connect 和远程连接按官方方式工作，并会直接读取官方版本已有的对话记录。

代价是两者不能装在同一台电脑上：安装中文分支前请先卸载官方桌面版，并备份 `~/.t3`。不要同时运行两个版本，也不要在两者之间来回切换；版本不一致时数据库可能无法回退。

桌面更新源和 CLI 安装脚本指向中文分支自己的 GitHub Releases，不会被官方英文版覆盖。Windows 从 `0.1.7-cn.2`、macOS 从 `0.1.7-cn.4` 起支持应用内自动更新。中文分支无法使用官方签名，macOS 上的通行密钥（Passkey）登录可能不可用，可改用其他登录方式。

## macOS 安装与更新

macOS 安装包（`T3-Code-<版本>-arm64.dmg`）只支持 Apple 芯片的 Mac。打开 dmg 后，先把 **T3 Code (Beta)** 拖进“应用程序”文件夹再打开；在 dmg 里直接运行的应用无法自动更新。

安装包使用中文分支的自签名证书，没有经过 Apple 公证，首次打开会被系统拦下。在“应用程序”里打开一次后，到 **系统设置 → 隐私与安全性** 点 **仍要打开**；也可以在终端执行 `xattr -dr com.apple.quarantine "/Applications/T3 Code (Beta).app"`。macOS 15 起，右键“打开”已不能跳过这一步。

放行之后，应用会从中文分支的 Releases 检查、下载并安装后续中文版，不需要再次放行。每个版本都用同一张证书签名，系统权限和钥匙串授权在更新后通常会保留；但从官方版换到中文版时，屏幕录制、麦克风等权限需要重新授予一次。更早的 macOS 预发布版不支持自动更新，请手动下载新版覆盖安装一次。
