# 简体中文界面

这是基于 [T3 Code](https://github.com/pingdotgg/t3code) 的非官方中文分支，保留原项目 MIT 许可证与版权声明。不是官方中文发行版，也不代表原团队提供支持。

## 切换语言

打开 **Settings → General → Language → Interface language**，选择 **简体中文**。也可以在设置搜索中输入“语言”或“Interface language”。随时选择 **English** 切回英文，无需重启。

第一次打开时跟随浏览器或系统首选语言：中文使用简体中文，其他语言使用英文。选择只保存在当前浏览器或桌面客户端，不会同步到其他设备。浏览器禁止存储时，本次会话仍可切换，但重启后可能无法保留。

## 当前范围

目前覆盖 Web 与 Electron 共用界面中的设置导航、设置搜索、常规设置，外观主面板、通知设置与快捷键编辑控件，以及常用侧边栏入口、项目空状态、发送/排队/中断操作、会话内查找和默认复制提示。主题/字体等嵌套设置及部分内置快捷键命令名仍保留英文。未完成的页面会继续显示英文；原生 iOS/Android 客户端和 Electron 原生菜单尚未汉化。

项目名、文件路径、代码、终端输出、模型回复和第三方错误原文不会自动翻译。界面语言不改变模型语言，也不修改任何服务端协议。

目前仅提供源码，尚未提供经过验证的中文安装包。上游 README 的下载和安装命令仍安装官方版本，不会安装此中文分支。请勿把本分支开发包安装到现有正式版的数据目录中；桌面分发标识、更新源和安装升级验证完成前，应使用独立开发环境。
