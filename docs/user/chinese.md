# 简体中文界面

这是基于 [T3 Code](https://github.com/pingdotgg/t3code) 的非官方中文分支，保留原项目 MIT 许可证与版权声明。不是官方中文发行版，也不代表原团队提供支持。

## 切换语言

打开 **Settings → General → Language → Interface language**，选择 **简体中文**。也可以在设置搜索中输入“语言”或“Interface language”。随时选择 **English** 切回英文，无需重启。

第一次打开时跟随浏览器或系统首选语言：中文使用简体中文，其他语言使用英文。选择只保存在当前浏览器或桌面客户端，不会同步到其他设备。浏览器禁止存储时，本次会话仍可切换，但重启后可能无法保留。

## 当前范围

目前已覆盖 Web 与桌面共用界面的设置、侧边栏、会话、命令面板、Git、拉取请求、文件预览、浏览器、设备和用量等主要区域。未完成的页面、部分旧格式文件预览和设备诊断仍可能显示英文；原生 iOS/Android 客户端尚未汉化。

项目名、文件路径、代码、终端输出、模型回复和第三方错误原文不会自动翻译。界面语言不改变模型语言，也不修改任何服务端协议。

桌面原生应用菜单在系统首选语言为中文时显示简体中文；它暂时不跟随上述 Web 界面语言选择，系统语言变更后需重新创建菜单或重启应用。原生更新提示框及其他上下文菜单仍可能显示英文；尚未完成真实桌面视觉验收。

## 与官方版本的关系

中文分支沿用官方的应用标识、`t3code://` 登录回跳协议、`~/.t3` 数据目录和 `t3` 命令，以便账号登录、T3 Connect 和远程连接按官方方式工作，并会直接读取官方版本已有的对话记录。

代价是两者不能装在同一台电脑上：安装中文分支前请先卸载官方桌面版，并备份 `~/.t3`。不要同时运行两个版本，也不要在两者之间来回切换；版本不一致时数据库可能无法回退。

桌面更新源和 CLI 安装脚本指向中文分支自己的 GitHub Releases。Windows `0.1.7-cn.2` 起支持检查后续中文版更新：隔离 Windows 环境中已验证下载、安装及数据保留，真实 GitHub 更新源仍需后续版本验证。macOS 请从 Releases 手动下载新版本。中文分支无法使用官方签名，macOS 上的通行密钥（Passkey）登录可能不可用，可改用其他登录方式。
