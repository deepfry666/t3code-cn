# 中文使用说明

这里是中文版的细节说明。第一次了解中文版，请先看 [README](../../README.md)。中文版是 [T3 Code](https://github.com/pingdotgg/t3code) 的非官方分支，不是官方发行版，也不代表原团队提供支持。

## 切换语言

打开 **设置 → 通用 → 显示 → 语言**（英文界面下是 **Settings → General → Display → Language**），选择 **中文（简体）**、**English** 或 **系统默认**，立即生效，无需重启。也可以在设置搜索里输入“语言”或“language”。

默认是“系统默认”：Web 版跟随浏览器的首选语言，桌面应用跟随系统的首选语言，首选中文时显示简体中文。官方另外支持的语言（如西班牙语）只翻译了官方覆盖的那部分文字，其余显示英文。以前在中文版里选过的语言，升级后会自动保留。选择只保存在当前浏览器或桌面客户端里，不会同步到其他设备。浏览器禁止存储时，本次仍可切换，但重启后可能恢复默认。

桌面应用的原生菜单、右键菜单和“检查更新”提示框跟随系统语言，不跟随上面的语言设置；改了系统语言后需要重启应用。

## 汉化范围

已覆盖 Web 和桌面共用界面的主要区域：设置、侧边栏、会话、命令面板、Git 与 PR、文件预览、浏览器、设备和用量。全部译文的英中对照在 [`i18n/zh-CN.json`](../../i18n/zh-CN.json)。

以下内容保持原样：

- 项目名、文件路径、代码、终端输出、模型回复和第三方错误信息。
- 启动恢复、浏览器权限和通行密钥等少数系统弹窗。
- iOS / Android 手机客户端：它们的中文由官方维护，中文版不单独汉化。

界面语言不改变模型回答所用的语言，也不改动任何服务端协议。

## 和官方中文的关系

官方从 [#31313](https://github.com/pingdotgg/t3code/pull/31313) 起也提供了一份中文翻译，目前只覆盖设置页的一小部分。中文版的原则是：代码跟官方走，措辞用中文版的。官方已经翻过的文字会换成中文版的译法，官方没翻到的地方继续由中文版补上，界面里只有一个语言开关。翻译规则和术语表见 [`i18n/README.md`](../../i18n/README.md)。

## 与官方版本共存

中文版沿用官方的应用标识、`t3code://` 登录回跳协议、`~/.t3` 数据目录和 `t3` 命令，所以登录、T3 Connect 和远程连接都按官方方式工作，也会直接读取官方版本已有的对话记录。

代价是两者不能装在同一台电脑上：安装中文版前请先卸载官方桌面版，并备份 `~/.t3`。不要同时运行两个版本，也不要在两者之间来回切换；版本不一致时数据库可能无法回退。

## 更新

桌面应用从中文版自己的 GitHub Releases 检查更新，不会被官方英文版覆盖。

- Windows 从 `0.1.7-cn.2`、macOS 从 `0.1.7-cn.4` 起支持应用内自动更新。更早的版本请手动下载新版覆盖安装一次。
- 从 `0.1.8-cn.2` 起，Releases 附带 macOS（Apple 芯片）和 Linux（x64、arm64）的 `t3` 命令行程序。在这些系统上可以使用命令行安装脚本、`t3 update`，以及在桌面应用里添加 SSH 远程环境。桌面应用会把与自己版本相同的命令行程序装到远程主机上，所以要先把桌面应用更新到新版本。
- Windows 和 Intel Mac 暂时不能作为 SSH 远程主机。

## macOS 安装

macOS 安装包（`T3-Code-<版本>-arm64.dmg`）只支持 Apple 芯片的 Mac。打开 dmg 后，先把 **T3 Code (Beta)** 拖进“应用程序”文件夹再打开；在 dmg 里直接运行的应用无法自动更新。

安装包使用中文版的自签名证书，没有经过 Apple 公证，首次打开会被系统拦下。在“应用程序”里打开一次后，到 **系统设置 → 隐私与安全性** 点 **仍要打开**；也可以在终端执行 `xattr -dr com.apple.quarantine "/Applications/T3 Code (Beta).app"`。macOS 15 起，右键“打开”已不能跳过这一步。

放行之后，后续更新会自动下载安装，不需要再次放行。每个版本都用同一张证书签名，系统权限和钥匙串授权在更新后通常会保留；但从官方版换到中文版时，屏幕录制、麦克风等权限需要重新授予一次。中文版没有官方签名，macOS 上的通行密钥（Passkey）登录可能不可用，可以改用其他登录方式。
